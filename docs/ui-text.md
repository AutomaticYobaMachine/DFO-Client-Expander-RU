# Строки интерфейса на двух языках (1.25.0)

Всё, что добавляет расширение, говорит на английском или русском. Это продолжение
пакетов описаний предметов (docs/item-text.md): те же каталоги локалей, тот же выбор
языка, тот же загрузчик `src/mod/item-text.cjs`.

## Где лежат слова

| Что | Таблицы | Кто читает |
|---|---|---|
| Окна и подписи мода в игре | `src/mod/item-text/<en\|ru>/ui/*.csv` | `page/dfo_ui_text.js` (`__dfoUi`) |
| Отчёт меток, ошибки сохранения | те же таблицы (`report.csv`, `store.csv`) | `hook.cjs` через `uiText()` |
| Вывод патчера | те же таблицы (`patcher.csv`) | `patcher.cjs` через `uiText()` |
| Окно установщика | `src/gui/locale/<en\|ru>/ui/installer.csv` | `src/gui/lang.go` (`T`) |

Формат один: `key,text,note`. Ключ — `область.имя[.имя…]` (латиница, цифры, дефис).
Перевод строки внутри текста пишется как `\n`. Подстановки:

- `{name}` — значение как есть;
- `{n:item|items}` — слово для числа: в английском две формы (one|other),
  в русском три (`{n:вещь|вещи|вещей}`: one|few|many; дробное число — вторая форма).

Отсутствующее значение оставляет подстановку видимой, отсутствующий ключ
показывается самим ключом — потеря слова заметна, а не молчалива.

Таблицы установщика лежат внутри Go-модуля и встраиваются в EXE (`go:embed`):
установщик обязан говорить даже тогда, когда его payload не распаковался.
Формат и проверки у них те же.

## Выбор языка

- **В игре** — как у описаний: русский при установленной и включённой русификации,
  иначе английский. Хук отдаёт странице одну локаль (`dfo-mod/dfo_ui_text_data.js`),
  английские строки лежат под ней, так что ключ без русского слова читается по-английски.
  `dfo_ui_text.js` и данные подключаются первыми, до остальных скриптов мода и модулей игры.
- **Установщик** — `--lang ru|en`, иначе сохранённый выбор переключателя
  (`%LOCALAPPDATA%\DFO-Client-Expander-RU\language.txt`), иначе язык интерфейса Windows
  (`GetUserDefaultUILanguage`, основной язык 0x19 — русский). Переключатель English/Русский
  в правом верхнем углу меняет все подписи сразу и запоминает выбор. Самообновление
  передаёт язык новому EXE через план (`resume.lang`).
- **Галочка «Русификация»** по умолчанию отмечена только на русской Windows. Сохранённый
  выбор установленного расширения важнее значения по умолчанию.
- **Патчер** получает `--lang` от установщика; без него (запуск через `Установить.cmd`)
  говорит по-русски.

## Что остаётся русским в коде

Русские строки в скриптах допустимы только там, где они и есть перевод игры
(при включённой русификации): `page/ru_items.js`, `page/ru_locale.js`, перевод родных
подписей сервисных окон в `page/dfo_services.js`, заплатки текстов квестов
и `[не назначено]` в `transforms.cjs`. Ещё — пробные глифы в `page/dfo_fonts.js`
и регулярные выражения, разбирающие уже переведённый текст игры. Всё прочее —
ключи. `test/ui-text.test.cjs` считает русские литералы по файлам и падает,
если их стало больше.

## Как добавить строку

1. Придумайте ключ в области своего файла (`loot.*`, `dungeon.*`, `town.*`, `svc.*`,
   `installer.*` …) и добавьте строку в **обе** таблицы — английскую и русскую.
2. В странице — `T('ключ', { имя: значение })` (в карте города и описаниях эффектов
   аксессор называется `L`/`T` — смотрите начало файла). Таблицы-словари держите
   ключами и переводите при чтении, а не при загрузке скрипта.
3. Числа показывайте через `__dfoUi.number()` (русские «1 234,5», английские «1,234.5»),
   даты — с `__dfoUi.tag`.
4. В Go — `T("installer.…", "имя", значение)`; для сообщения, которое может
   пережить переключение языка (заметка внизу окна, состояние обновления), храните
   `sayKey(...)`, а не готовую строку.

## Проверки

- `test/ui-text.test.cjs`: одинаковые таблицы и ключи в en/ru (мод и установщик),
  одинаковые подстановки, отсутствие русского в английских таблицах, существование
  каждого ключа, названного в коде, плюралы, запрет новых русских литералов.
- `src/gui/lang_test.go`: таблицы установщика, подстановки, плюралы, порядок выбора языка.
- Браузерные стенды подключают пакет через `tools/ui-text-stand.cjs`: стенд карточек
  на обычной странице — английский, на `?ru` — русский; остальные стенды по умолчанию
  русские, `DFO_UI_LOCALE=en` запускает их с английским пакетом (их проверки текста
  написаны по-русски).
- `tools/test-installer-ui.py` запускает окно с `--lang ru` и проверяет переключатель
  в обе стороны.
