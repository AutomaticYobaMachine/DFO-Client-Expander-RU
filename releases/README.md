и установленная игра. Во встроенной кнопке «Инструкция» есть подробности.

[GitHub Releases](https://github.com/AutomaticYobaMachine/DFO-Client-Expander-RU/releases).
Там же доступны ZIP с инструкцией и лицензиями. Эта копия EXE в репозитории
даёт прямую загрузку независимо от состояния очереди Actions.
