# Ресурсы пользовательских 2D-иконок предметов (`src/mod/item-icons`)

Эта директория зарезервирована под будущие кастомные 2D-иконки предметов (спрайты `.png` и таблицу их привязок), которые будут добавлены на следующем этапе вместо 3D-иконок Morrowind.

## Зачем это нужно

В текущем моде:
- замена иконок предметов 3D-моделями из Morrowind resource pack отключена в `worldTick` и `enhancedInventory`;
- все слоты экипировки, рюкзака, контейнеров, карточек предметов (`.bigicon`), хотбара и HUD-слотов рук напрямую используют стандартный 2D-пайплайн иконок.

Чтобы заменить дефолтные фрагменты Daggerfall-спрайтов на полноценные 2D-иконки для экипировки, оружия и прочих предметов без конфликтов с внешним видом персонажа и без костылей в DOM, используется встроенный механизм игры — тот же пайплайн, через который в клиенте реализован двемерский огнестрел и кастомные вендорские текстуры (`gilded` / `textureReplacement` / `wagonKinds`).

## Целевой пайплайн интеграции (по аналогии с двемерским огнестрелом)

1. **Регистрация собственных текстур (`textureReplacement.addVendorTextures`)**
   - Изображения иконок (`.png`) регистрируются в отдельном кастомном архиве текстур мода с `standIn: true`.
   - Файлы раздаются клиенту через локальный обработчик `dagger://game/dfo-mod/...` в `src/mod/hook.cjs` без модификации оригинальных архивов игры (`app.asar` / паков Daggerfall).

2. **Разделение иконки в UI и спрайта на 2D-кукле персонажа (`wagonKinds` + `{ forPaperDoll }`)**
   - Поиск 2D-картинки предмета в UI вызывает реестр кастомных иконок `wagonKinds` с `forPaperDoll: false` — сюда подключаются наши кастомные PNG-иконки из `src/mod/item-icons/`.
   - Отрисовка 2D-куклы персонажа в `paperDoll` передаёт `forPaperDoll: true`. Благодаря этому замена иконки в инвентаре / карточке / хотбаре остаётся полностью независимой от одетого спрайта на 2D paperdoll (и от 3D-фигуры персонажа).

## Текущий статус

- Папка подготовлена заранее; сами PNG-иконки и трансформ загрузки ещё не сгенерированы.
- При добавлении ассетов сюда войдут:
  - папка со спрайтами `.png` (и при необходимости подпапки по категориям: оружие, броня, одежда, украшения и т.д.);
  - манифест/таблица соответствий предметов (`group`, `templateIndex`, варианты `rarity` / `material`) на записи кастомного архива;
  - подключение копирования ассетов в `tools/build.sh` и раздачи в `src/mod/hook.cjs`.
