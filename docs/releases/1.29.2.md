# 1.29.2 — геометрия инвентаря

Исправление по скриншоту из игры (8 ноября 2026): в одиночном режиме ширина настоящего окна инвентаря теперь составляет до **1600 px** с отступами 12 px от краёв экрана. Ширина левой части экипировки остаётся **540 px**; дополнительные пиксели отданы только правой панели.

Все девять категорий с числом предметов должны размещаться в **одну строку** исключительно над правым списком, не сдвигая экипировку/температуру вниз.

В списке — **два растягивающихся равных столбца** прямоугольных карточек; ограничение ширины 360 px из 1.29.1 снято. Режим рядом с контейнером сохраняет родную ширину и один столбец предметов.

Ширина реального DOM-элемента .pack-win также закрепляется после перерисовки, чтобы поздние игровые правила CSS не вернули его к 1040 px. Изменения находятся в отдельной ветке; это исправление не сливается с main автоматически.
