# 1.29.3 — исправлена именно правая колонка инвентаря

По игровому скриншоту 1.29.2 внешняя рамка действительно достигла 1600 px, однако левая часть экипировки заняла примерно 1100 px: изменение CSS не закрепило размер внутренней сетки игры.

В версии 1.29.3 после штатного синхронного render() выставляются **на самом `.pack`** `display:grid` и `grid-template-columns:540px minmax(0,1fr)` с приоритетом `important`. Также закрепляется реальная ширина `.pack-win`, сетка девяти категорий с числами (одна строка в правой панели) и две равные, растягивающиеся колонки карточек без ограничения 360 px. Перестановок DOM и изменений блока экипировки/температуры нет.

Дополнительно появился тест измерения реального макета в Chromium, включая имитацию поздней игровой таблицы CSS, способной перезаписать распределение колонок. Режим с открытым контейнером проверяется отдельно и должен сохранять родную геометрию.

Фактическое отображение внутри запущенной сетевой игры может подтвердить только снимок после установки этой сборки.
