# Контекст проекта

- Этот репозиторий — неофициальное расширение пользовательского клиента
  Daggerfall Online, а не родительский проект игры.
- Основной оригинал: https://github.com/Lattymoy/daggerfall-js-source.
  Другие репозитории Lattymoy — вспомогательные источники, если они относятся
  к решаемой задаче.
- Родительский проект обновляется очень часто. Перед адаптацией хуков и перед
  заявлением о совместимости проверяйте актуальные исходники и релиз оригинала.
  Не считайте старую локальную копию или номер версии из README текущими.
- Версия игры 0.1.14487 указана в импортированном README.txt как ранее проверенная;
  она не означает, что мод проверен с последним релизом оригинала.
- Исходная база расширения: DFO Mod 1.9.0 из пользовательского архива
  dfo-mod-source(1).zip. При первоначальном импорте все 568 файлов сохранены
  без изменения содержимого; внешний каталог архива dfo-mod/ убран.
- Сохраняйте сведения об авторстве и лицензиях переводов и исходных таблиц.

# Работа с исходниками

- Код установщика находится в src/gui/ (Go, Win32); код патчера и хуков —
  в src/; данные перевода — в data/; инструменты — в tools/.
- Команда сборки из корня: sh tools/build.sh. Нужны Go 1.24+ и Python 3;
  результат предназначен для Windows amd64. Скрипт пересоздаёт dist/.
- tools/build-ru-pack.py меняет данные перевода на месте. Не запускайте его
  для обычного импорта или проверки, когда изменение перевода не требуется.
- Для проверки хуков выбранного релиза используйте tools/fetch-build.mjs
  и tools/check-build.cjs. Проверку синтаксиса и успешную сборку не выдавайте
  за проверку совместимости с текущей игрой.

# Детектор лута рядом

- Новая функция описана в docs/nearby-loot.md. Это представление ссылок на
  исходные предметы, не дополнительное хранилище. Не переносите вещи в
  промежуточный контейнер при открытии, фильтрации или сортировке.
- Подбор выполняйте только штатными planTake/applyTransfer из живого исходного
  списка с сохранением сетевого протокола тела/комнаты. Не выполняйте повторный
  перенос из массива отображения и не генерируйте содержимое чужих тел локально.
- Тесты: node --test --test-isolation=none test/nearby-loot.test.cjs.
  Для проверки настоящих функций и сетевого стенда оригинала задайте
  DFO_UPSTREAM_DIR. Команды браузерной проверки и сборки — в документации.

# Лутфильтр и автолут (1.11.0)

- Спецификация — docs/loot-filter.md. В обоих режимах достаточно ЛЮБОГО
  отмеченного тега; не вводите AND между группами без отдельного запроса.
- Фильтр отображения и автолут независимы. Автолут запускается только по J,
  до показа списка; галочки, пресеты, сортировка и фоновые кадры не подбирают вещи.
- Общий кеш имеет отдельный раздел loot. Запись данных города не должна его
  затирать, как и раздел dungeons; используйте loot-store.cjs и проверку revision для настроек.
- Пресеты и правила содержат только настройки/ID, никогда игровые сущности.
- Дополнительные тесты: test/loot-filter.test.cjs; полный браузерный сценарий
  проверяет диалоги, отмену, JSON-экспорт, перезапуск и обход чёрного списка автолутом.

# Доступность и массовый подбор (1.11.1)

- Все способы подбора используют живой collider текущей сцены. Радиус 15 м,
  предел разницы высот 1,25 м, прямой проход с опорой и проверкой препятствий.
  surfaceHit нужен для уличного грунта; raycast сам по себе видит только меши.
- Перед переносом и внутри visitor проверка геометрии всегда свежая; кеш 150 мс
  разрешён только для списка. Отсутствующий коллайдер не даёт доступа по радиусу.
- «Забрать все» подбирает текущие строки с фильтрами/поиском, проверяя вместимость
  после каждого переноса. Закрывать окно только при успехе и пустом списке;
  отказ показывать штатным сообщением. Кнопка не затрагивает скрытые строки.
- Ошибки записи возвращают настройки и интерфейс к подтверждённому кешу.
  Проверять revision также при сохранении пресета; не оставлять файл при отказе
  записи кеша. Дополнительные проверки: test/loot-access.test.cjs.

# Карточки данжей (1.12.x)

- Спецификация, источники и проверки — docs/dungeon-intel.md. Основной оригинал
  остаётся Lattymoy/daggerfall-js-source; проверенная база 1.12.0 — исходники
  5fbed9eb6567457a021b19bccdb823f6f7f8c4d9, опубликованные ассеты 0.1.14512.
- Только найденные географические данжи на Overworld; города, специальные
  комнаты и ненайденные «?» не получают карточек и раскрывающих подписей.
- Метаданные брать из нативных таблиц и функций. Не вызывать mutable selector
  encounterTable или генерацию dungeonLocationFor ради прогноза/размера:
  они могут изменить общий RNG. Использовать encounterTableChoices и builtSizeFor.
- Метки используют штатный HUD, включая его hit box/фильтры; не создавать
  второй HTML-слой кликабельных меток. ЛКМ открывает одну карточку; «В путь»
  вызывает штатный маршрут, при отказе окно остаётся открытым.
- Карточка привязана к rising/up штатного Overworld, а не только к режиму
  exterior персонажа. Опускание карты и смена host закрывают её; перед
  путешествием состояние проверяется заново, в том числе внутри привязки мира.
- Прогноз, неизвестные серверные данные и датированные наблюдения различать
  в интерфейсе. Отсутствие spawn ledger не доказывает отсутствие первого входа.
- Раздел dungeons общего кеша содержит только нормализованные сводки, максимум
  200 записей. Не сохранять игровые сущности, инвентарь или содержимое сундуков.
- Тесты: test/dungeon-intel.test.cjs, test/dungeon-bridge.test.cjs (нужны
  DFO_UPSTREAM_DIR и DFO_BUILD_DIR) и tools/test-dungeons-browser.cjs.

# Установщик (1.13.x)

- Имя продукта — DFO-Client-Expander-RU, автор — AutomaticYobaMachine;
  приписка — «Создано специально для русского сообщества DFO Online.».
  Сохраняйте отдельное авторство переводов и их лицензии.
- Кнопка перехода на GitHub убрана по запросу пользователя. Начальная высота
  окна — 1040 логических пикселей с ограничением по рабочей области экрана;
  на небольших экранах остаётся прокрутка списка.
- Нативное окно: src/gui/ui_windows.go и win32_windows.go; операции/поиск —
  install_windows.go и discovery_windows.go. Каталог функций и аргументы
  инъектора общие, в options.go. Не добавлять галочку без передачи её в --set.
- Игрок получает самостоятельный EXE со встроенным payload. Генерация архива,
  иконки/manifest/version resources и сборка выполняются tools/build.sh;
  payload_windows.zip и resources_windows_amd64.syso не коммитятся.
- Выбор ru/marks/nearbyLoot/dungeons независим; onlyVisited зависит от marks.
  При установке enabled=1, остальные пользовательские настройки сохраняются.
  Физический перевод оболочки исключать через --no-ru при снятой русификации.
- Не вызывать Win32-функции изменения контролов из рабочих goroutine.
  Ответ проверки старого пути/старой ревизии выбора не должен затирать новый.
  Во время изменения ASAR нельзя закрывать окно или убивать дочерний процесс.
- Тесты: go test ./... в src/gui, test/packaging.test.cjs и
  tools/test-installer-ui.py (Wine/Xvfb, настоящий EXE, отдельный тестовый профиль).
