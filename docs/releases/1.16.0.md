**DFO-Client-Expander-RU 1.16.0 — навигация в данже.**

Автор: **AutomaticYobaMachine**. Создано специально для русского сообщества DFO Online.

- **[Скачать готовый EXE для Windows x64](https://github.com/AutomaticYobaMachine/DFO-Client-Expander-RU/releases/download/v1.16.0/DFO-Client-Expander-RU-1.16.0.exe)**.
- **[ZIP с EXE, инструкцией и лицензиями](https://github.com/AutomaticYobaMachine/DFO-Client-Expander-RU/releases/download/v1.16.0/DFO-Client-Expander-RU-1.16.0.zip)**.

В первой вкладке **«Сводка»** обозревателя данжа появились четыре направления:
**к выходу**, **к сундуку с аурумом**, **к ближайшему элитнику**, **к цели задания**.
Для нескольких заданий есть выбор конкретного. Окно открывается по **K**
или вашей назначенной кнопке; обе привязки и прежний кеш сохраняются.

После выбора окно закрывается, и светящаяся голубая линия на полу показывает
проход. Она учитывает стены и этажи, огибает препятствия и обновляется при
отклонении или движении цели. Перед закрытой дверью линия останавливается:
откройте её вручную, чтобы продолжить. Известные карте переходы между участками
учитываются по направлению; линия продолжается после перехода. При отсутствии
пешего пути показывается объяснение.

Отмена — **K → Сводка → Убрать маршрут**. Выход и смена комнаты очищают линию.
Навигатор не двигает персонажа, не открывает двери, не подбирает предметы,
не забирает аурум и не выполняет задания. Автообновление сводки сохранено;
выбор задания и фокус больше не сбрасываются при изменении данных.

Закройте игру, запустите новый EXE и нажмите **«Обновить расширение»**.
Всё необходимое встроено; Go, Node.js и сборка исходников игроку не нужны.

Проверочная база: опубликованные ассеты **0.1.14517**, коммит оригинала
`a3eb1605ea1dc391b691fe314377458a7e63e483`. Проверены нативная геометрия,
поиск проходов, worker, перекрытие линии стенами в WebGL и интерфейс.
