# Обновления и диагностика установщика — 1.22.0

При запуске EXE проверяет последний стабильный GitHub Release
`AutomaticYobaMachine/DFO-Client-Expander-RU`. Равные/старые версии, черновики
и prerelease пропускаются. Для получения обновлений игрокам не нужны GitHub
токены: репозиторий должен быть публичным, файлы — опубликованы в Releases.
Отправка исходников в main и артефакт Actions сами по себе не являются релизом.

## Согласие перед загрузкой

Если найдена свежая версия, появляется диалог с текущей/новой версией и
кнопками «Да» / «Нет». По умолчанию выбран отказ. До «Да» загружаются только
метаданные релиза: EXE и контрольная сумма не скачиваются, ничего не заменяется.
«Нет» оставляет текущую программу открытой без повторных предложений по таймеру.
Кнопка «Обновления…» позволяет проверить снова. Сбой сети оставляет ручную
установку доступной. Проверка и загрузка не блокируют оконный поток.

После «Да» загружаются EXE и `.exe.sha256` из Releases только этого репозитория.
Проверяются размер, SHA-256, digest GitHub (если указан), продукт, версия,
Windows x64 GUI и протокол служебного запуска. Ошибка оставляет текущий EXE
и открытое окно, а причину записывает в журнал.

Помощник готовит копию рядом с портативным EXE, затем после завершения старого
окна атомарно заменяет файл. Новое окно подтверждает успешную распаковку/запуск.
Если подтверждения нет, помощник возвращает прежний EXE и запускает его снова.
Он останавливает только собственный неподтверждённый дочерний процесс, не игру.
Другие окна установщика, работа патчера, захват клавиши и модальные диалоги
откладывают предложение или перезапуск. Настройки/неприменённый выбор переносятся.

## Инъекция только по кнопке

Ни запуск программы, ни статус клиента, ни закрытие игры, ни возобновление
после самообновления **не изменяют ASAR**. Для установки, обновления мода или
применения настроек нужно нажать соответствующую кнопку. Ошибка патчера
переключает окно на журнал и позволяет исправить причину/повторить попытку.
Таймаут проверки статуса не применяется к операции записи ASAR.

Старые `--auto-install` / `--auto-uninstall` больше ничего не устанавливают:
они открывают окно и оставляют предупреждение в журнале. `--no-self-update`
отключает сетевую проверку в текущем запуске.

Первый переход на 1.22.0 — вручную скачанным EXE. Протокол обновления повышен
до 2, план требует `userApproved`. Установщики 1.19–1.21 с протоколом 1 отклонят
новый EXE при служебной проверке, не выполняя прежний тихий переход. В 1.18 и
более ранних версиях самообновление отсутствует. Последующие версии протокола 2
обновляются через описанный диалог.

## Постоянный полный журнал

`dfo-mod-installer.log` автоматически дописывается в каталог кеша игры,
обычно `%APPDATA%\DFO Online`. После определения фактического `userData`
туда переносится вся текущая сессия, включая старт до проверки клиента.
Если стандартный каталог недоступен, используется
`%LOCALAPPDATA%\DFO-Client-Expander-RU\logs`; актуальный путь указан в журнале.

Сохраняются время, версия/PID, пути, команды патчера, stdout и stderr,
результаты проверки, ошибки и коды завершения, диагностика помощника обновления
и аварийный вывод Go. Длинные строки не обрывают чтение потока. Предыдущие
сессии в файле не затираются. Кнопка «Полный журнал» открывает этот файл;
«Сохранить журнал…» экспортирует всю текущую сессию. Окно показывает последние
64 КиБ, чтобы большой вывод не скрыл последнюю ошибку и не перегружал Win32 Edit.
При недоступности обоих каталогов доступен экспорт из памяти.

## Проверки

`go test -race ./...` и `go vet ./...` в `src/gui` проверяют версии, загрузку,
целостность/адреса, план/согласие, перенос настроек, полный журнал, конкурирующую
запись, резервный каталог и завершившийся с ошибкой дочерний процесс с выводом
более 1 МБ. `tools/test-installer-ui.py` проверяет настоящий Win32 EXE,
старый автоматический ярлык, ошибку/повтор операции и сохранность кеша.
`tools/test-updater-ui.py` использует локальный HTTP transport внутри тестового
EXE: отказ без скачивания, согласие/перезапуск без инъекции, перенос выбора,
неверную сумму и откат при повреждённом payload. Реальные релизы не скачиваются
и не публикуются этими тестами.
