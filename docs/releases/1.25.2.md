# DFO-Client-Expander-RU 1.25.2

Автор: **AutomaticYobaMachine**. Создано специально для русского сообщества DFO Online.

Исправления после полной перепроверки двуязычной версии 1.25.

- **Английская версия без русских слов в окне создания заклинаний.** Список вариантов
  эффекта («Варианты: Обычный · Истинный») показывался по-русски и без русификации.
  Теперь там слова самой игры (Normal · True); по-русски — только с русификацией.
- **Сообщения лутфильтра и пресетов** (например, «фильтр с таким именем уже существует»)
  всегда на языке окна: хук передаёт ключ ошибки, окно переводит его своим пакетом.
- **Строки интерфейса работают быстрее:** каждая строка разбирается один раз,
  поиск перевода примерно в 5 раз быстрее. Это важно для подписей, которые рисуются
  каждый кадр.
- **Журнал самообновления** пишется на языке окна установщика.

**English.** In the English install the spellmaker's effect variants no longer show Russian
words (the game's own Normal · True now); loot filter and preset messages always speak the
window's language; interface strings are about 5× faster to look up; the self-update log follows
the installer's language.

Проверено на опубликованном клиенте **0.1.14574** (последний релиз игры на 7 ноября):

- **Установка.** Настоящий патчер ставит мод в пробный ASAR. Без русификации — только
  английские таблицы, странице отдаётся английский пакет; с русификацией — обе локали
  и русский пакет; если русификация установлена, но выключена, — английский.
- **Ключи.** Все 475 ключей, которые код собирает на лету, есть в обоих языках.
- **Стенды на русском и английском.** Карточки данжей, сводка, навигация, лут, сервисные
  окна (все 93 эффекта заклинаний с описанием) и калибровка проходят целиком на обоих
  языках. Их проверки берут текст из тех же таблиц, а аудитор ловит пропущенные ключи
  и русский текст в английских окнах мода: ни одного пропуска. Также проходят карточки
  предметов (английская и русская страница), матрица состояний, балансировка, аудит всех
  шаблонов игры, витрина карточки и проекция карты.
- **Шрифты.** Оба стенда шрифтов проходят на файлах мода. Оригинальные шрифты игры
  не используются и для проверок больше не нужны.
- **Модульные тесты** проходят и вместе, и каждый файл отдельно, как в GitHub Actions.
  Сборка EXE и тесты установщика проходят.

Окна установщика под Wine и живая сетевая игра не проверялись.

[Строки интерфейса](https://github.com/AutomaticYobaMachine/DFO-Client-Expander-RU/blob/v1.25.2/docs/ui-text.md).

**Для установки достаточно EXE для Windows 10/11 x64.** ZIP содержит тот же EXE, инструкции на двух языках и лицензии. Отдельные Go/Node.js и сборка исходников не нужны. Перед применением закройте игру; инъекция запускается только по кнопке установщика.

Пользователям **1.22.0–1.25.1** обновление предложит сама программа с подтверждением «Да/Нет». При переходе с более ранних версий скачайте новый EXE вручную. SHA-256 находится в отдельном файле рядом с каждым архивом/EXE.
