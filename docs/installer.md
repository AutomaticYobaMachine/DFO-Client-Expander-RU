# Установщик DFO-Client-Expander-RU 1.13.1

Автор: **AutomaticYobaMachine**. Создано специально для русского сообщества
DFO Online. Имя используется в окне, именах дистрибутива, свойствах PE/EXE,
инструкции и журнале; авторство и лицензии материалов перевода сохранены.

## Для игрока

Запустите `DFO-Client-Expander-RU.exe`, предварительно закрыв игру. Это один
самостоятельный файл: данные, перевод и инъектор находятся внутри. Установщик
распаковывает их во временную папку и удаляет её при завершении работы.
Отдельно устанавливать Node.js, Go или распаковывать папки `mod/data/patcher`
не требуется. Нужен установленный клиент DFO Online, Windows 10/11 x64.

Игра ищется рядом с EXE, по сохранённому пути, реестру и обычным каталогам.
«Выбрать игру…» позволяет указать `DFO Online.exe` вручную. «Проверить» обновляет
состояние клиента после его закрытия. Если игра запущена, установка и удаление
недоступны; инъектор также повторяет штатную проверку процесса перед записью.

Четыре независимых галочки сопровождаются широкими полями описаний:

| Компонент | Что получает игрок |
| --- | --- |
| Русификация | Интерфейс, предметы, квесты и книги на русском |
| Метки и карта города | Метки заведений на Overworld, подробная карта города; отдельное «Только посещённые» |
| Лут рядом | Общий интерфейс наземного дропа и убитых врагов, фильтры/пресеты/сортировка/подбор; ограничения стен и этажей |
| Сведения о данжах | Подписи, персональные индексы, карточки и мини-гайд; отдельная кнопка путешествия |

Автолут включается и настраивается в игре. Галочка «Лут рядом» не включает
автоматический подбор сама. Назначенная ранее клавиша сохраняется; подпись
компонента читает её из настроек клиента.

«Установить выбранное», «Обновить расширение» или «Применить настройки»
выбирается по состоянию клиента. Повторный запуск читает сохранённые галочки.
«Удалить расширение» возвращает исходный ASAR; пользовательские настройки,
пресеты и кеш остаются. Пустой выбор не запускает бессмысленную установку.

Окно растягивается, на небольшом экране прокручивается список компонентов,
а действия установки остаются на месте. Tab проходит по полям и галочкам;
пробел переключает галочку. При фокусе на компоненте вне видимой области
список прокручивается к нему. Отдельная вкладка «Журнал» показывает операции
и ошибки; журнал можно сохранить. «Инструкция» открывает встроенный README.

В 1.13.1 начальная высота увеличена с 900 до 1040 логических пикселей с
ограничением по рабочей области экрана. Кнопка перехода на GitHub убрана.

## Устройство

- `src/gui/options.go` — единый каталог, выбор, чтение старого конфига и
  аргументы `--set`. Отсутствующие новые поля сохраняют значения по умолчанию;
  явный `false` не теряется.
- `ui_windows.go`, `win32_windows.go` — обычный Win32 без стороннего GUI runtime:
  нативные checkboxes, доступные названия контролов, перенос текста, прокрутка,
  фокус, масштабирование PerMonitorV2 и фоновые операции без блокировки окна.
- `install_windows.go`, `discovery_windows.go` — поиск, проверка клиента,
  запуск инъектора и журнал. Состояние контролов меняет только UI-поток.
  Устаревший ответ другого выбранного пути или старой ревизии выбора отбрасывается.
- `payload_windows.go` — чтение доверенного встроенного ZIP в отдельную временную
  папку с проверками путей, размеров и CRC. Дочерний процесс изменения архива
  не привязан к таймауту проверки состояния и не прерывается закрытием окна.
- `tools/windows-resources.py` — стандартным Python создаёт COFF-ресурсы:
  иконку, manifest, имя/автора/версию/описание. Версии Go и JSON должны совпадать.
- `src/patcher.cjs` — запускается EXE игры через `ELECTRON_RUN_AS_NODE`,
  поддерживает `enabled`, `ru`, `marks`, `nearbyLoot`, `dungeons`, `onlyVisited`.
  При выключенном переводе GUI передаёт `--no-ru`, чтобы исключить перевод
  самой оболочки. Остальные настройки, включая клавишу лута, не заменяются.

Внутренние имена `dfo-mod/`, `dfo-mod.json`, `dfo-mod-cache.json` и суффикс
чистой копии сохранены для обновления предыдущих версий. Путь поиска хранится
в `%LOCALAPPDATA%\DFO-Client-Expander-RU\game-path.txt`; старый файл возле
прежнего установщика также читается. Игровые настройки остаются в профиле игры.

## Сборка и проверка

```sh
sh tools/build.sh
(cd src/gui && go test ./...)
node --test test/packaging.test.cjs
```

Сборке нужны Go 1.24+, Python 3 и POSIX shell. Проверке инъектора нужен Node.js.
`dist/payload/` содержит тот же набор, что встроен в EXE; в пользовательском
ZIP — только EXE, README и лицензии. Старые архивы с номерами версий сохраняются.

Сквозная проверка настоящего Win32-окна:

```sh
DFO_WINDOWS_NODE=/path/to/windows/node.exe python3 tools/test-installer-ui.py
```

Нужны Wine, Xvfb, xdotool, Go и Pillow. Можно указать `DFO_WINE`, `DFO_XVFB`,
`DFO_XDOTOOL`, `DFO_GO`, `DFO_SCREENSHOT_DIR`; для повторного использования
подготовленного изолированного Wine-профиля — `WINEPREFIX`. По умолчанию
используется временный тестовый профиль. Официальный Windows Node здесь
заменяет только EXE клиента для исполнения инъектора: игровая сетевая сессия
этим стендом не имитируется. Тестовый Win32-драйвер не входит в установщик.

Проверяются четыре галочки и описания, Tab/пробел, зависимость «Только посещённые»,
пустой выбор, прокрутка к фокусу в небольшом окне, установка из единственного
EXE без соседних файлов, точный выбор функций, восстановление после перезапуска,
повторное включение перевода, журнал/экспорт/отмену сохранения, исходные байты
ASAR и сохранность кеша.
Проверка упаковки дополнительно разбирает PE-ресурсы и проверяет встроенный
payload, название/автора/версию, иконку и DPI manifest.

Проверено для 1.13.0: четыре теста Go и два теста упаковки прошли.
Дополнительно прошли все 46 регрессионных тестов лута, фильтров, геометрии,
сетевых переносов, сведений о данжах и привязок оригинала.
Сквозной сценарий на настоящем EXE под Wine 10 с Windows Node 22.16.0 прошёл,
включая выбор/отмену файла клиента, экспорт/отмену журнала и пути с кириллицей.
Скриншоты сняты при полном и уменьшенном окне. Исправлены формат MULTI_SZ
фильтров файловых диалогов, перерисовка прежней вкладки, показ всей карточки
при переходе фокуса и разделение этапа/прогресса в компактном окне.
Это проверка установщика; живая игровая сессия и физическая Windows-машина
в этом стенде не использовались.
