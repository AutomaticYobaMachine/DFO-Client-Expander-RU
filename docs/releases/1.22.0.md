# DFO-Client-Expander-RU 1.22.0

Автор: **AutomaticYobaMachine**. Создано специально для русского сообщества DFO Online.

- Инъекция, обновление мода и удаление выполняются только по кнопке. Автоматическая установка при запуске, после закрытия игры и после обновления EXE отключена; старые автоматические ярлыки открывают обычное окно.
- При запуске проверяются новые стабильные релизы. Перед скачиванием появляется диалог «Да/Нет». Отказ оставляет программу открытой; проверить повторно можно кнопкой «Обновления…».
- После согласия EXE проверяется по размеру, SHA-256, продукту и версии. Сохраняются выбранные функции и клавиши; при неудачном запуске возвращается предыдущий EXE. Применение к игре после перезапуска требует отдельного нажатия.
- Ошибка патчера оставляет окно открытым и показывает причину в журнале. Полный журнал `dfo-mod-installer.log` автоматически дописывается рядом с кешем игры, обычно `%APPDATA%\DFO Online`. Кнопка «Полный журнал» открывает его. Сохраняются stdout/stderr, ошибки запуска/завершения и диагностика обновления; длинный вывод не обрывает чтение.

**Первый переход на 1.22.0 выполните вручную:** скачайте новый EXE и запустите его. Старые версии протокола 1 не выполняют тихое обновление до новой версии протокола 2. После перехода будущие обновления предлагаются новым диалогом.

Игроку нужен только EXE для Windows 10/11 x64. ZIP содержит тот же EXE, инструкцию и лицензии. Отдельные Go/Node.js и сборка исходников не требуются. Перед применением к клиенту закройте игру. Контрольная сумма находится рядом с соответствующим файлом.

Проверено: Go/race/vet, реальное Win32-окно под Wine, ошибка и повтор патчера, клавиатура/Mouse4/5/NumPad, сохранение кеша, отказ без скачивания, согласие и замена EXE без инъекции, отказ при неверной сумме и откат повреждённого обновления. Это проверки установщика; они не заменяют сетевую игру.
