# DFO-Client-Expander-RU

**Автор: AutomaticYobaMachine.** Создано специально для русского сообщества
DFO Online.

Неофициальное расширение пользовательского клиента **Daggerfall Online**:
русификация, метки заведений, карта города, детектор лута и карточки данжей. Здесь хранятся исходники
расширения, а не исходники самой игры.

## Установщик 1.13.1

**DFO-Client-Expander-RU.exe** — один файл со всеми компонентами внутри.
Игроку не нужны отдельные Node.js, Go или папки с данными установщика.

Закройте игру, запустите EXE, проверьте найденный клиент и отметьте нужные
функции: русификацию, метки/карту города, лут рядом, сведения о данжах.
Напротив каждой галочки находится широкое поле с объяснением. Кнопка установки
применяет выбранный набор, обновление сохраняет кеш и настройки. «Только
посещённые» — отдельная зависимая настройка меток.

Окно меняет размер, список прокручивается, Tab/пробел работают с галочками.
Действия установки остаются видимыми; ход работы и сохранение отчёта доступны
во вкладке «Журнал». «Инструкция» открывает документацию. Окно по умолчанию
выше и показывает все четыре компонента, когда позволяет экран. Название,
автор и приписка о сообществе также записаны в свойства EXE.

Подробности сборки и проверок: [docs/installer.md](docs/installer.md).

## Сведения о данжах (1.12.1)

Найденные данжи на Overworld получают подпись в три строки:

```text
[Логово дракона - 18 ранг] S/M/L Собственное имя
Элитный/Обычный данж, постоянный данж/порождённый, ЧЧ:ММ
|☠☠☠|◆◆|↑↑↑↑| ★ - 2,5
```

Угроза красная, добыча золотая, рост зелёный, Слава белая. Время показывается
только для порождённого данжа с доступной записью журнала; иначе таймер неизвестен.
Ненайденные «?» сохраняют своё штатное поведение и не раскрывают сведения.

**ЛКМ** открывает одну карточку с вкладками **Оценка**, **Враги**, **Добыча**,
**Ресурсы**, **Мир и группа**, **Посещение**. Первая вкладка объясняет персональные
оценки; **Мини-гайд** раскрывает правила расчёта. **В путь** запускает штатное
путешествие и закрывает карточку, если игра приняла маршрут. Esc закрывает верхнее
окно. Города и специальные залы сохраняют штатные метки.

Карточка закрывается при опускании Overworld, включая автоматический выход
из-за опасности, и при смене игрового мира. После закрытия карты «В путь»
не запускает маршрут. Недоступные списки лута в наблюдениях обозначаются
как неизвестные, а не как ноль предметов.

Прогноз использует текущие уровень, навыки, Удачу, оружие и Славу персонажа,
таблицы и формулы оригинала. Он не строит данж и не расходует общий генератор
случайных чисел. Фактическая сетевая комната может отличаться. Наблюдения после
входа сохраняются отдельно со временем в разделе `dungeons` общего кеша;
настройки лута и карта города при этом сохраняются.

Отключение: `"dungeons": false` в `%APPDATA%\DFO Online\dfo-mod.json`.
Подробности, источники, формулы и границы доступных данных:
[docs/dungeon-intel.md](docs/dungeon-intel.md).

Проверены исходники оригинала `5fbed9eb6567457a021b19bccdb823f6f7f8c4d9`
и опубликованные ассеты **0.1.14512**: все ожидаемые хуки, автоматические тесты
и браузерные сценарии. Дополнительно проверены хуки и карточка на **0.1.14487**,
закреплённой загрузчиком оригинала. Живая игровая сессия и GUI под Windows здесь
не проверялись.

## Лут рядом (1.11.1)

**J** (физическая клавиша, в том числе в русской раскладке) открывает детектор
лута в радиусе **15 м**: предметы убитых противников и наземные кучи в одном
штатном окне инвентаря. В расширенном интерфейсе доступны поиск, категории,
редкость, материал, сортировка и «Забрать все» для текущего фильтра.

**Забрать все** пытается перенести весь текущий список с учётом фильтров и
поиска. Если всё подобрано, окно закрывается; если остались вещи, оно остаётся
открытым. При нехватке вместимости игра показывает своё сообщение, стопки
подбираются в допустимом количестве. Проверка веса повторяется для каждой вещи.

Детектор, ручной подбор и автолут работают только при прямом доступе:
стены, закрытые двери, непроходимые проёмы и провалы исключают лут.
Разница высот ограничена **1,25 м**, поэтому соседние этажи не агрегируются.
За углом нужно сначала пройти персонажем; окно не ищет обходной маршрут.

Это **представление лута, не дополнительный контейнер**. Предметы остаются в
исходных кучах и трупах до подбора. Мод не создаёт копий предметов, не сохраняет
их в отдельном хранилище и не перемещает их при открытии или сортировке окна.
Подбор выполняется штатными функциями игры непосредственно из исходного списка
в инвентарь с проверкой веса и допустимого количества. Ящики, обыскиваемые
могилы, мебель, тайники и останки игроков в список не входят.

Повторное нажатие J не открывает второе окно. Клавиша не срабатывает при вводе
в чат, поиске, выборе фильтра или поверх другого игрового окна.

В `%APPDATA%\DFO Online\dfo-mod.json` можно изменить клавишу или отключить функцию
(остальные настройки файла нужно сохранить):

```json
{
  "nearbyLoot": true,
  "nearbyLootOptions": { "keyCode": "KeyJ" }
}
```

По умолчанию J заменяет штатное действие быстрого открытия лута под прицелом.
В классическом интерфейсе используются его штатные вкладки; поиск и кнопка
сортировки, как у каравана, доступны в расширенном интерфейсе игры.

**Сетевая граница:** оригинал подтверждает чужой дроп по своим правилам
доступности и дистанции. Радиус детектора не расширяет разрешённую оригиналом
дистанцию выдачи чужого дропа. Полноценная проверка в живой сетевой сессии нужна
перед использованием с ценным лутом.

### Лутфильтр и автолут

В окне появились две кнопки:

- **Лутфильтр** открывает галочки тегов в два ряда. Каталог охватывает игровые
  категории, группы, наземные типы, редкость, материалы, свойства, аффиксы и виды
  предметов, включая отсутствующие сейчас рядом. Группу тегов можно выбрать
  отдельно или найти тег поиском.
- **Автолут** позволяет включить подбор по J и отметить теги либо конкретные
  виды/разновидности предметов. По умолчанию автолут выключен. Он работает
  независимо от лутфильтра, поиска и фильтров самого окна.

Режимы лутфильтра взаимоисключающие: активный золотой, другой серый. В **белом
списке** достаточно любого отмеченного совпадения, чтобы показать предмет;
в **чёрном списке** любое совпадение скрывает его. Пустой белый список ничего
не показывает, пустой чёрный — показывает всё. Фильтр влияет только на отображение.

Внизу диалога — **Сохранить**, **Загрузить**, **Закрыть**. Сохранение запрашивает
имя, выгружает JSON-файл и добавляет пресет в общий кеш программы. Загрузка
предлагает список сохранённых пресетов; выбор применяется только после кнопки
«Загрузить». Вложенные окна имеют «Отмена»; Esc закрывает только верхнее окно.
При ошибке записи галочки и режим возвращаются к состоянию сохранённого кеша;
ошибка видна в интерфейсе. Обновление списка пресетов синхронизирует открытый
диалог, в том числе после изменений из другого окна клиента.

Настройки и пресеты хранятся в разделе `loot` существующего
`%APPDATA%\DFO Online\dfo-mod-cache.json`; копии файлов пресетов — в
`%APPDATA%\DFO Online\dfo-mod-loot-presets\`. Обновления кеша карты города
сохраняют этот раздел. Пресет содержит режим и теги лутфильтра; правила автолута
хранятся отдельно и загрузкой пресета не заменяются.

При нажатии J автолут сначала делает одну попытку забрать подходящие вещи
напрямую из исходных списков. Подобранное в окно не попадает. Оставшееся
показывается с учётом лутфильтра. Если всё было подобрано, окно не открывается;
следующее J без лута позволяет открыть пустое окно и изменить настройки.
Настройка галочек сама ничего не подбирает. Непоместившиеся вещи остаются у
источника; ограничения сетевой выдачи оригинала сохраняются.

Подробности и проверки: [docs/loot-filter.md](docs/loot-filter.md).

Архитектура, изученные источники и результаты проверок:
[docs/nearby-loot.md](docs/nearby-loot.md).

## Сборка

Для сборки нужны POSIX shell, **Go 1.24 или новее** и **Python 3**. Для инструментов
проверки и работы с JavaScript нужен **Node.js** (в облачной среде — 24).
Сторонние npm-пакеты и Python-пакеты не требуются.

Из корня репозитория:

```sh
sh tools/build.sh
```

Скрипт собирает установщик для **Windows 10/11 amd64** и создаёт
`dist/DFO-Client-Expander-RU-1.13.1.exe` и ZIP с тем же именем версии.
В `dist/DFO-Client-Expander-RU/` лежит установщик с инструкцией и лицензиями,
в `dist/payload/` — встроенный набор для проверки инъектора. Ресурсы Windows
и встроенный архив генерируются из исходников средствами Python.

При запуске сборки `dist/` пересоздаётся; ранее собранные архивы с номерами
версий сохраняются. Для установки и проверки в игре нужен установленный
клиент DFO Online под Windows. Для самой сборки сторонние Python-пакеты
или утилиты создания Windows-ресурсов не требуются.

При изменении исходных материалов перевода пакет можно пересобрать отдельно:

```sh
python3 -I tools/build-ru-pack.py
```

Эта команда изменяет данные в `data/ru-pack/` и `data/ru/`; её результат нужно
проверять как отдельное изменение перевода.

## Проверка совместимости с игрой

В репозитории есть инструменты загрузки выбранных ресурсов релиза и проверки
того, что хуки находят ожидаемые места и изменённый JavaScript разбирается:

```sh
# Проверенная при разработке 1.12.0 версия; перед новой адаптацией проверьте релиз оригинала.
NODE_USE_ENV_PROXY=1 node tools/fetch-build.mjs 0.1.14512 /tmp/dfo-build-0.1.14512
node tools/check-build.cjs /tmp/dfo-build-0.1.14512
```

Эта проверка требует доступа к GitHub Releases и не заменяет проверку в игре.
